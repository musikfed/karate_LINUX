KARATE LINUX — КНИГА 1 «БЕЛЫЙ ПОЯС»
ЛАБОРАТОРНАЯ РАБОТА 13 — APT И ДОВЕРЕННЫЕ ИСТОЧНИКИ

Среда: собственная учебная Ubuntu 24.04 LTS, интернет, учётная запись
с разрешённым sudo. Желательно заранее создать снимок виртуальной машины.
Не выполняйте задания на рабочем или чужом сервере.

ПОДГОТОВКА: ТОЛЬКО ЧТЕНИЕ
1. Зафиксируйте версию ОС:
   cat /etc/os-release
2. Посмотрите пакетный менеджер и источники:
   apt --version
   apt policy
   ls -l /etc/apt/sources.list.d/
3. Если файл ubuntu.sources существует, прочитайте его:
   cat /etc/apt/sources.list.d/ubuntu.sources
   Определите поля Types, URIs, Suites, Components и Signed-By.

ИССЛЕДОВАНИЕ ПАКЕТА
4. Проверьте, установлен ли tree:
   command -v tree
5. Изучите пакет и кандидатную версию:
   apt search tree
   apt show tree
   apt-cache policy tree
   dpkg -l tree
   Отсутствие установленного пакета не означает ошибку репозитория.

ПРАКТИКА НА УЧЕБНОЙ ВМ
6. Обновите индекс:
   sudo apt update
7. Если tree не установлен, установите его из официального источника:
   sudo apt install tree
8. Проверьте результат:
   tree --version
   dpkg -l tree
   apt-cache policy tree
9. Посмотрите доступные обновления без их установки:
   apt list --upgradable
10. Объясните разницу между apt update, apt upgrade
    и full-upgrade. Не запускайте полное обновление в этой работе.

РАЗБОР СБОЕВ
Разберите, что проверять при ошибках:
- Unable to locate package;
- Temporary failure resolving;
- Could not get lock;
- NO_PUBKEY / неверная подпись;
- Unmet dependencies.
Не удаляйте lock-файлы и не отключайте проверку подписи.

ПРОВЕРКА
В отчёте укажите выпуск Ubuntu, источник, название пакета,
установленную и доступную версию, выполненные команды и их результат.
Не включайте пароли и секреты. Источники не изменялись.

Открытых готовых ответов нет: криптографическая методика решения
упражнений появится в третьей книге «Зелёный пояс — Практика».
