KARATE LINUX | КНИГА 1 «БЕЛЫЙ ПОЯС»
ЛАБОРАТОРНАЯ РАБОТА 15 — СЕТЕВОЙ ПАСПОРТ

ЦЕЛЬ
Определить адреса, маршруты, DNS, локальные порты
и наличие SSH-клиента. Не менять сетевые настройки.

СРЕДА
Собственная учебная Ubuntu 24.04 LTS или отдельная виртуальная машина.
При отсутствии интернета зафиксируйте это, не придумывайте результат.

1. hostnamectl --static
2. cat /etc/os-release
3. ip -br link
4. ip -br address
5. ip route
6. resolvectl status
7. getent ahosts example.com
8. ss -lnt
9. ss -lun
10. command -v ssh
11. ssh -V
12. command -v ufw
13. sudo ufw status
14. ping -c 3 127.0.0.1

ОБЪЯСНИТЕ
Какая команда показывает интерфейс, IP и маршрут?
Чем DNS отличается от проверки доступности узла?
Почему ping без ответа не доказывает, что сервис отключён?
Значит ли наличие ssh-клиента, что работает ssh-сервер?
Какие риски при изменении UFW на удалённой машине?

КОНТРОЛЬ
Не запускайте ufw enable, ufw disable, ufw deny и
не редактируйте сетевую конфигурацию.
Не подключайтесь по SSH к чужим системам.
В отчёт не включайте личные IP-адреса или секреты.

Ответы будут предоставляться только по схеме,
разработанной в книге 3 «Зелёный пояс: Практика».
