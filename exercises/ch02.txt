KARATE LINUX | КНИГА 1. БЕЛЫЙ ПОЯС
ЛАБОРАТОРНАЯ РАБОТА 02 — ТЕРМИНАЛ, BASH И ИСТОРИЯ КОМАНД

Условие: учебная Ubuntu 24.04 LTS / Bash. Не вставляйте пароли в терминал.
Действия выполняются только в учебном каталоге.

ЗАДАНИЯ
1. Выполните whoami, pwd и hostname; объясните результаты.
2. Сравните type cd и type ls, затем command -v ls.
3. Создайте каталог "$HOME/Карате Linux" и найдите его через ls -ld.
4. Выполните history 10. Найдите прежнюю команду с помощью Ctrl+R (например, pwd).
5. Покажите поиск в списке без запуска найденной строки: history | grep -F 'pwd'.
6. Выполните команду с ошибочным именем (например, karate-linux-no-command) и запишите сообщение об ошибке.
7. Исправьте опечатку, повторно запустите правильную безопасную команду.

ПРОВЕРКА
Не путайте просмотр истории и исполнение старой команды.
Перед повторным запуском через Enter проверьте всю найденную строку.

Ответы намеренно не размещены в открытом виде.
