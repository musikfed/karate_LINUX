ЛАБОРАТОРНАЯ РАБОТА 04 — УСТАНОВКА UBUNTU

ЦЕЛЬ
Создать безопасный учебный стенд Ubuntu 24.04 LTS, не изменяя рабочий диск.

УСЛОВИЯ
Законно полученный официальный ISO; проверенная SHA-256; отдельная виртуальная
машина с новым виртуальным диском; запас ресурсов у основной системы.
Перед записью на любые носители проверьте выбранное устройство.

ЗАДАНИЯ
1. Сверьте SHA-256 ISO с официальной суммой поставщика.
2. Создайте ВМ. Зафиксируйте 2–4 vCPU, объём ОЗУ, ёмкость виртуального диска.
3. Установите Ubuntu с автоматической разметкой ТОЛЬКО пустого диска ВМ.
4. Отсоедините установочный ISO и войдите как обычный пользователь.
5. Выполните отдельно, каждую команду с новой строки:
   cat /etc/os-release
   uname -r
   whoami
   lsblk -f
   findmnt /
   df -h /
6. Проверьте man, tree и nano через command -v. Недостающие пакеты
   установите из официальных репозиториев.
7. Сохраните локальный паспорт стенда и снимок состояния виртуальной машины.

КОНТРОЛЬ
ОС загружается без ISO. Корневая файловая система и пользователь определены.
Рабочие накопители основной системы не изменялись.
