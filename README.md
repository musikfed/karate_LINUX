# Karate Linux — учебные материалы PEGINELAB

Автор: Греп Пайп (Grep Pipe). Серия практических книг и курсов «Karate Linux».

## Книга 1 — «Белый пояс»

Цель полного книжного макета — около 270 страниц A5. Рабочий план: 16 глав и приложения. Материалы создаются поэтапно с проверкой команд и иллюстраций. Основной практический стенд — Ubuntu 24.04 LTS, особенности Astra Linux рассматриваются отдельно.

Здесь размещаются **текстовые файлы заданий**, сопровождающие книгу. Они не запускаются автоматически. Файлы: `exercises/ch01.txt`, `exercises/ch02.txt`, `exercises/ch03.txt`.

В печатной версии адрес указывается без схемы и активной ссылки: `github.com/musikfed/karate_LINUX`. Для полной навигации репозитория используйте адрес в строке браузера.

## Правила редакции
- Не заменять словосочетание «лабораторная работа» сокращениями «лаборатория».
- Для хронологии ОС использовать собственные аккуратно подписанные учебные пиктограммы с годами.
- Перед практикой указывать зависимости, различать установленные по умолчанию и необязательные пакеты.
- Показывать типовые ошибки, диагностику и безопасное исправление; опасные команды не рекомендовать без объяснений.
- Примеры и текстовые задания должны работать в учебной среде без необходимости раскрывать личные данные.
- Ответы к заданиям не публиковать открытым текстом: подготовка зашифрованных ответов и методика расшифровки — задача **книги 3 «Зелёный пояс: Практика»**. Предполагаемый стандарт — AES-256-GCM с надёжным формированием ключа из парольной фразы, уникальным salt и nonce; протокол, формат, а также способ безопасной передачи секрета утвердить в книге 3 до шифрования.
- Никаких реальных паролей, API-ключей и токенов в Git.
